# Kết quả phân tích cổ phiếu khi sử dụng với skill [stock-analysis][https://github.com/hiennguyen9874/pi-starter-kit/blob/main/.pi/skills/stock/stock-analysis/SKILL.md] thông qua mcp [sstock](https://sstock.vn/blog/huong-dan-su-dung-mcp-sstock-vn)

## Hướng dẫn sử dụng

- Cài đặt pi coding agent
- Clone repo https://github.com/hiennguyen9874/pi-starter-kit
- `npm install --prefix .pi/extensions/profile`
- chạy pi, chạy new, reload pi lần đầu để tự động cài extension
- Login tài khoản anthropic `/login anthropic`
- Chọn model `claude-opus-5-5`, thinking high
- Gõ /profile, enter, chọn `research/sstock`
- Login mcp qua, /mcp, `sstock`, Sign In
- new, reload pi
- `/skill:stock-analysis Phân tích cổ phiếu SSI`
